DataBridge Capabilities & Features

Multi-Engine Database Support

Configure and manage connections to **SQL Server**, Oracle, DB2, PostgreSQL, MySQL, Databricks, and Lakehouse architectures.

File & Object Storage Ingestion

Directly parse and load flat files (CSV, Parquet, Excel, Text) and connect directly to Azure Blob cloud storage containers.

Advanced Data Quality checks

Configure and run custom validation checks on column properties (Null values, Duplicate limits, RegEx checks, custom ranges).

Target Load Configuration Modes

Choose between clear-target Full Loads, Incremental Appends, or track history with Slowly Changing Dimensions (SCD Type 2).

Automated Pipeline Scheduling

Schedule pipelines to execute daily, weekly, monthly, or using customizable high-frequency Crontab cron expressions.

Detailed Audit Logging & Reports

Analyze records extracted, rows loaded, schema mismatch errors, execution speeds, and comprehensive validation logs.
